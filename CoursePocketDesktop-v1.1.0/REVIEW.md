# 课袋电脑版：第一性原理与对抗性审查

审查日期：2026-10-13。审查对象：Windows 电脑版 1.0.0。改进版本：1.1.0。

## 从目的推导审查标准

课程资料整理器的核心价值是让用户找得到、拿得回、信得过自己的资料。功能数量不能补偿资料丢失或错误的成功提示。因此按以下顺序审查：

1. **资料保存是承诺。** 只有文件与索引一致时才能宣称成功；中断或失败必须保留恢复路径。
2. **删除必须可解释。** 删除失败不能先丢失记录，尚未提交的删除应可恢复。
3. **备份必须能恢复。** ZIP 成功生成不代表内容完整；必须验证真实字节，而非相信文件名或索引。
4. **输入不是事实。** 备份中的路径、ID、哈希、大小、扩展名和时间都要检查。
5. **用户的动作应得到可预期结果。** 关闭编辑器不能悄悄丢掉内容，部分失败不能显示全部成功。

## 已复现并修复的问题

| 优先级 | 触发方式与原行为 | 1.1.0 的行为 | 验证 |
| --- | --- | --- | --- |
| P1 | 导入后文件损坏，再覆盖备份：旧版照样成功生成 ZIP，恢复时才失败，还会覆盖原好备份 | 打包时逐字节计算 SHA-256 并核对长度；失败不替换已有备份 | 对抗测试 1 |
| P1 | 本地副本缺失或损坏，重新导入原件：只比较索引哈希，跳过了唯一修复机会 | 先验证现有副本；不完整时原位替换，保留名称、标签、收藏和 ID，单独报告修复数 | 对抗测试 2、3 |
| P1 | 文件被占用时“彻底删除”：先删除索引，实际文件删除失败 | 先移入明确的删除暂存目录，再提交索引；失败回滚，启动时处理未完成事务 | 对抗测试 4、12–15 |
| P1 | 外部打开采用有限黑名单；空扩展名配合可执行文件名、遗漏的脚本类型可以绕过 | 外部打开采用明确文档类型白名单，空扩展名和未列入格式只能导出 | 对抗测试 10；未执行危险程序 |
| P1 | 主索引丢失时把已有文件目录当成新库，下一次保存可能覆盖恢复线索 | 发现既有文件、旧索引或暂存状态即拒绝创建空库；提供经文件校验的上次索引恢复，保留损坏索引 | 对抗测试 8、16、17 |
| P1 | ZIP 解压前只检查声明长度，实际解压流与声明不一致时可能先写入超额数据 | 元数据和附件都在读取过程中限制真实字节数，附件同时验证长度与哈希 | 对抗测试 11；原有损坏 ZIP 回归测试 |
| P2 | Windows 文件路径不区分大小写，ID 集合却区分，可能让两条记录指向同一文件 | 校验时使用不区分大小写的集合并统一 GUID 表示 | 对抗测试 5 |
| P2 | 空哈希、负数长度、过长字段或过多条目可进入资料库 | 校验哈希格式、字段长度、大小、条目数和索引总量 | 对抗测试 6、7及回归测试 |
| P2 | 导出允许进入应用内部目录，失败时没有清晰的部分成功统计 | 禁止导出到内部目录；逐项验证后原子发布，每项成功/失败分别计数，失败不留下半个输出文件 | 对抗测试 9、18 |
| P2 | 关闭或取消编辑器直接丢失未保存笔记 | 有修改时提供保存、放弃、继续编辑；保存失败留在编辑器 | UI 测试 8–10 |
| P2 | 作业截止日被保存成时间瞬间，跨时区可能变成另一日期 | 新增明确的 `yyyy-MM-dd` 日历日期，优先使用它；保留旧数据读取兼容 | 对抗测试 19、日期回归测试 |
| P2 | 双击表头或空白处可能打开之前选中的资料 | 仅真实数据行的双击触发打开 | 代码检查；未自动点击第三方程序 |

新增“检查资料完整性”，检查缺失、损坏、被修改的文件，以及没有索引记录但仍留在磁盘的副本。未登记副本会被报告并保留，不自动删除。

## 证据与测试结果

先给旧版加入不改变业务逻辑的故障测试入口，复现了 9 个独立问题：**0 通过、9 失败**。修复后这 9 个同一场景全部通过，随后增加其他故障检查。

- `audit-before.txt`：旧版的 9 个复现失败。
- `audit-after.txt`：**21 个对抗性检查全部通过**。
- `test-results.txt`：**16 个功能回归检查全部通过**。
- `preview.png.ui-tests.txt`：**10 个 WPF 控件检查全部通过**，包括保存/放弃/继续编辑分支。

合计 **47 项检查通过**。旧版兼容性使用实际发布的 1.0.0 EXE 生成备份，再交给新版本恢复，不是仅用新版代码模拟旧格式。

中断测试通过构造“文件已暂存但索引未提交”和“索引已提交但文件未清理”这两个磁盘状态，重新启动存储层验证恢复。文件锁用真实 Windows 文件共享锁制造。并未进行真实断电、磁盘故障或强制杀进程的耐久性实验。

## 还不能声称解决的边界

- 没有把外部阅读器放入沙箱；允许的文档格式仍可能含有恶意内容，白名单不等于文档安全证明。SHA-256 用于检测内容不一致，不验证备份来源身份。
- 没有杀毒、加密备份、云同步或代码签名。Android 与电脑备份格式仍不同。
- 普通关闭可保护未保存编辑；强制结束进程或断电时，未点保存的笔记仍可能丢失，尚无自动草稿恢复。
- 未对 50 GB / 100000 条资料的上限做压力测试；大库、巨幅/畸形图片、ZIP 中央目录解析和磁盘耗尽仍需专项测试。
- 未全面验证多 Windows 会话同时访问、跨磁盘异常、各种第三方阅读器、实际拖拽及所有 DPI 环境。
- 为避免目录重定向，本版敏感文件操作会拒绝符号链接和目录联接。它不是抵御同一 Windows 账户下其他恶意进程的安全边界。

这些限制意味着本次结果是有复现证据的缺陷修复和防护增强，而不是“绝无数据丢失”或“完全安全”的保证。

## 升级与恢复

关闭旧版，解压新版，运行 `CoursePocket.exe`。使用相同数据目录，无需迁移；建议先用旧版导出备份，保留一份原件。新版启动和测试不会自动操作用户的真实资料库；所有审查测试使用独立测试目录。

若主索引损坏，新版可以提示恢复上次索引，并先校验其全部引用文件。上次索引不是完整备份，可能不包含最新一次改动。如果上次索引也无法恢复：关闭应用，先将整个原数据目录复制保存，再将原目录改名留存；重新启动应用创建新库，然后合并恢复已有的完整 ZIP 备份。不要直接删除故障目录。
