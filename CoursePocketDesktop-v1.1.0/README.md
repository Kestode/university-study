# 课袋电脑版 1.1.0

Windows 本地课程资料整理器。无需账号、联网或启动服务器。

## 启动

将发布 ZIP 解压到电脑上的普通文件夹，双击 **CoursePocket.exe**。保留同目录的 `CoursePocket.exe.config`。程序基于 Windows WPF 和 .NET Framework 4.7.2 或更新版本，面向 Windows 10 / 11。本机已完成编译、运行与界面渲染验证；尚未覆盖不同电脑、缩放比例或阅读器的兼容性。

程序是未进行商业代码签名的自用版本。无需管理员权限。

## 相比手机版增加了什么

| 功能 | 用法 |
| --- | --- |
| 学期与课程 | 按学期筛选课程，记录教师或备注；右键课程编辑 |
| 拖拽、多文件导入 | 把文件拖到资料列表，或点“导入资料”；保存独立副本 |
| 内容去重 | 同课程内相同内容只导入一次；已有副本丢失或损坏时，重新导入原件可修复 |
| 多选批量整理 | Ctrl / Shift 多选，批量移动课程、追加标签、加入收藏 |
| 搜索与过滤 | 搜索文件名、课程、标签、备注与笔记正文；按类型筛选 |
| 多种排序 | 最近更新、最近导入、名称、大小；最近导入视图显示近 7 天 |
| 文件预览 | 图片以及 UTF-8 文本预览；较大文件和其他格式使用外部软件 |
| 本地笔记 | 创建和编辑文字笔记，支持 Markdown 文本保存与导出 |
| 作业计划 | 记录截止日期、说明、完成状态，标记逾期和剩余天数 |

| 批量导出 | 导出文件和笔记，同名文件自动编号，避免覆盖 |
| 完整备份 | ZIP 包含课程、文件、笔记、标签、收藏、作业及回收站 |

## 常用操作

1. 在左侧“课程目录”旁点 **＋** 新建课程。
2. 选中课程后点 **导入资料**，或把文件拖到中间列表。
3. 选中资料，右侧查看信息和预览。双击可打开文件或编辑笔记。
4. 按住 Ctrl 或 Shift 选择多份资料，然后使用“批量整理”。
5. **Ctrl+F** 聚焦搜索；列表中按 **Delete** 会请求删除确认。
6. 在“备份与恢复”中导出完整备份到另一个磁盘或设备。

文件导入仅复制，不移动或修改原件。只有白名单内的文档类型能直接打开（例如 PDF、DOCX、PPTX、XLSX、常见文本和图片）；未列入的格式请先导出并自行选择软件。外部软件打开的是**只读副本**，不会同步修改到资料库；需要编辑附件时，请先导出，修改后重新导入。可执行文件和脚本不会从应用内直接运行。

## 数据位置与备份

默认数据位于当前用户的：

```text
%LOCALAPPDATA%\CoursePocketDesktop
```

主索引为 `library.json`，文件副本在 `files` 中，未完成的删除暂存在 `delete-staging` 中，外部打开生成的只读副本在 `open-copies` 中。不要手动改动索引和文件 ID。删除程序文件不会删除此处的数据；删除这个数据目录会删除资料库。

索引采用原子替换写入，保留一次上一版本 `library.json.previous`；这只是异常恢复辅助，不代替完整 ZIP 备份。主索引打不开时，可尝试恢复上次索引，新版会先验证引用文件，并保留损坏索引。

恢复会保留当前资料并合并备份。同名、同学期课程会合并；重复恢复会新增资料与作业副本。恢复前会校验文件路径、完整性与内容哈希，失败时不提交索引并移除本次复制的文件。

完整备份上限：50 GB 文件总量、100000 份资料、32 MB 元数据。备份为普通 ZIP，未加密。

## 当前边界

- 与安卓首版没有自动同步，两个版本的备份格式不同。跨端请导出实际文件再导入。
- 不对 PDF、Word、PPT 等附件正文做全文索引，不提供 OCR。
- Markdown 是文本编辑和预览，不是富文本排版渲染。
- 暂不递归导入文件夹；请选择或拖入实际文件。
- 图片超过 30 MB、文本超过 4 MB 时不在侧栏预览；文本预览最多 10000 个字符，笔记预览最多 12000 字符，编辑时可查看全文。
- 关闭应用后不会发送作业通知；在应用内查看截止日期。
- PDF、Office 文档需要电脑已安装相应阅读软件。
- 存储空间统计包含回收站中的资料文件，不含临时打开副本及索引。

## 验证

- 16 项数据检查：导入、去重、笔记和作业持久化、ZIP 往返恢复、哈希校验、重复恢复、导出防覆盖、回收站、非法备份回滚、日期时区、文件名与路径保护。
- 21 项对抗性检查：损坏备份、缺失副本修复、文件锁导致的删除/索引提交失败、中断恢复、路径与内容校验、旧版备份兼容等。`REVIEW.md` 列出问题和证据。
- 10 项真实 WPF 控件检查：原有 7 项列表与界面检查，加上未保存编辑的保存、放弃、继续编辑分支。
- 使用示例资料渲染界面检查。预览图中的示例不会加入用户资料库。
- 未自动化验证系统文件选择框、实际拖拽、第三方阅读器启动和多显示器缩放。

源码目录运行 `build.ps1` 可用系统 C# 编译器重新构建。无需下载第三方依赖。
